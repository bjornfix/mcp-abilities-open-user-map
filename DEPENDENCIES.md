# Dependencies

MCP Abilities - Open User Map depends on four runtime systems. Each link goes to the authority for the named dependency.

- [WordPress 6.9 or newer](https://wordpress.org/download/) provides the Abilities API used to register the location operation.
- [PHP 8.0 or newer](https://www.php.net/supported-versions.php) provides the required server runtime.
- [Open User Map](https://wordpress.org/plugins/open-user-map/) owns the `oum-location` post type and native location data.
- [WordPress MCP Adapter](https://developer.wordpress.org/news/2026/02/from-abilities-to-ai-agents-introducing-the-wordpress-mcp-adapter/) exposes registered WordPress abilities through Model Context Protocol.

Install and activate these dependencies before this add-on.
