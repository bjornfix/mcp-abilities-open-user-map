# Dependencies

MCP Abilities - Open User Map depends on four runtime systems. Each link goes to the authority for the named dependency.

- [WordPress Abilities API](https://developer.wordpress.org/apis/abilities-api/) requires WordPress 6.9 or newer and registers the location operation.
- [PHP 8.0 or newer](https://www.php.net/releases/8.0/en.php) provides the required server runtime.
- [Open User Map](https://wordpress.org/plugins/open-user-map/) owns the `oum-location` post type and native location data.
- [WordPress MCP Adapter](https://github.com/WordPress/mcp-adapter/) exposes registered WordPress abilities through Model Context Protocol.

Install and activate these dependencies before this add-on.
